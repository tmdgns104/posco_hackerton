# SteelTrust G8 간편 통합 릴리스 — 변경 및 검증 보고

## 무엇을 바꾸었나요?

- 기본 Streamlit 실행 파일: `app_demo.py` → `app_easy.py`
- 첫 화면은 핵심 비교 결과만 표시하고 강판·정상/불량·슬래그·능동 탐색·도움말로 분리
- 복잡한 원본 CSV, 오분류 상세, 회귀시험 사례, 원본 해시 등은 접기 메뉴 안에 배치
- 정상/불량 K0/K1의 동일 3,262회 평가에서 신규 미검출/오경보를 계산하는 읽기 전용 엔진 추가
- 강판 V0/G1의 원본 360장과 잡음 3,240회 평가를 명확하게 구분
- 슬래그는 동일 B/S 240개 구간에 한하여 G5-B, G6-B, G6 Deep 직접 비교
- G1 오류 사례 ZIP 재실행 및 해시 확인 기능 간편 화면에서 제공
- 기존 G1·슬래그 연구 모델·추론·Adaptive Red Team 엔진 변경하지 않음
- 웹을 통한 임의 `.joblib` 업로드/로드 기능은 포함하지 않음
- 전문용 G7 메뉴는 `START_G7_LEGACY_WINDOWS.cmd`로 분리
- G8 Python 3.12 독립 가상환경 `.venv_g8` 설치기 제공

## 직접 실행 확인

- 신규 순수 데이터 평가 단위 테스트 **6개 통과**
- 기존 슬래그 비교/Adaptive Red Team/G1 핵심 회귀 포함 **25개 테스트 통과**
- 구 G1·CNN 등의 봉인된 기존 실험/모델·코드 해시 **82개 검사 중 실패 0개**
- G1 `run.case(...)` 재추론, 사례 ZIP 내보내기, 사례 ZIP 재검증 성공
- G6B/G5B SSFD `B-1.csv` 기준 `S-1.csv` 실제 추론 10구간 정상 출력
- V0 Adaptive Red Team 교란 시험 1개 이미지에서 능동·무작위 탐색 실행 확인
- 간편 UI 각 화면을 Streamlit 대체 스텁으로 호출해 기본 분기·데이터 처리 확인
- Python 파일 문법 컴파일 통과 및 ZIP 내부 CRC 검사 예정

## 확인하지 못한 항목

- 이 실행 컨테이너에는 실제 Streamlit 패키지가 없어 Windows 브라우저 UI를 직접 기동하는 시험은 수행할 수 없었음. 따라서 **UI가 모든 사용자 PC에서 오류 없이 작동한다고 보장하지 않음**.
- GitHub `dohyeon` 브랜치의 전체 원격 저장소 파일과 체크포인트를 자동 다운로드하지 못했음. 접근 가능한 `README`, `app_demo.py`, `demo_ui.py`, `inspection_ui.py`, `p1_tabular_ui.py`, `security.py` 등 공개 원문을 분석해 UX 개념을 선별 적용함.
- KSDD2 원본 이미지와 GitHub에서 추가된 원격 인증/감사/모델 등록 기능을 이 G8 배포본에 포함하지 않음.
- 실제 제철소 현장 검증, 안전/자동제어 신뢰성 인증, 모델 자동 재학습·교체, 신뢰도 보증은 제공하지 않음.
