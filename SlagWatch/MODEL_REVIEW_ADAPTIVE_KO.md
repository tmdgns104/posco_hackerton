# SteelTrust G2 — 모델 검증 요약 (2026-11-09)

## 실제로 확인한 사항

**원본 ZIP과 기존 G1 프로젝트 비교:** `surface_g1`, `cnn_v1`, `artifacts`, `models` ZIP 내부의 파일은 기존 UI에 있는 동일 경로 파일과 SHA-256이 일치했습니다. `inspection_binary` 패키지는 신참 원본 그대로 `experiments/inspection_binary`로 추가했습니다. Python 검사에서 봉인된 기존 코드·가중치·기록 관련 **82개 파일 검사 모두 통과**했습니다. 다만 `artifacts`의 4개 폴드 joblib은 원본에 기재된 서명값이 없어 파일 존재/현재 SHA를 기록한 것이며, 과거의 진품을 증명한 것은 아닙니다.

**실제 추론 확인:** `V0,V1,V2,G1`이 NEU validation 이미지에 대해 실행됨을 확인했고, `C0,C1` 진동 체크포인트도 0.5초 입력에 대해 수치 점수를 반환했습니다. `K0,K1` joblib은 모델 헤드와 임계값을 로드할 수 있었습니다. KSDD2 이미지/마스크가 없어서 독립 추론 정확도 검사는 하지 않았습니다. 기존 fold별 RF 기준 모델도 원본 진동 입력의 판정 결과를 반환했습니다.

## 앞으로 개선해야 할 핵심 문제

- **결함 미탐을 오경보보다 중요하게 관리:** K1은 오경보 감소만 보면 좋아 보이지만 불량 미탐이 늘어 공정 품질 목표에 부적절합니다. 클래스·교란별 불량 재현율 하한을 먼저 정한 후 개선을 선택하세요.
- **외부 분포 변화:** G1의 가우시안 잡음 강건성만으로 렌즈·속도·조명·코일 변화까지 보증할 수 없습니다. 실제 설비/카메라별 독립 데이터 확보가 다음 단계입니다.
- **레이블 의미 보존:** 자동 변형이 실제 결함을 흐리거나 지우면 기존 클래스 라벨이 유지된다는 보증이 없습니다. Adaptive 결과는 사람이 검토하고 유효한 실패만 따로 집계해야 합니다.
- **데이터 누수:** 이미 시험에 사용한 이미지로 Adaptive의 최적화/모델 선택을 하면 그 데이터는 더 이상 독립 시험셋이 아닙니다. 본 G2의 새 실험은 validation 탐색이며 외부 test 성과를 주장하지 않습니다.
- **모델 일반화:** 강판은 결함 6종 분류, KSDD2는 정상/불량, SSFD는 슬래그 유동 감지로 입력 및 오류 비용이 다릅니다. 하나의 '정확도'만으로 서열화하면 안 됩니다.
- **시연 목표:** random과 adaptive를 같은 예산·시드로 여러 이미지/그룹에 적용, 최소 오류 조건 및 첫 실패까지의 시도 수를 분석하고 개선 후보를 독립 평가에 넘기는 것.

## 중요한 범위 제한

Adaptive Red Team의 현재 대리모델은 **RandomForestRegressor**로, 시험 기록으로부터 다음 교란 조건을 학습해 선택합니다. 이는 머신러닝 기반 능동 탐색이며 별도의 딥러닝 FailureNet이 학습되었다는 뜻은 아닙니다. 이번 작업에서는 봉인된 기존 모델 헤드의 재학습 및 자동 배포를 수행하지 않았습니다.
