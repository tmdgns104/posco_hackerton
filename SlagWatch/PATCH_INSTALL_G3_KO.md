# SteelTrust G3 경량 패치 설치

이 패치는 **SteelTrust G2 Adaptive Red Team 전체 설치본** 전용입니다.

1. 기존 G2 전체 폴더를 별도 위치에 백업합니다.
2. ZIP 안의 `SlagWatch` 폴더를 기존 G2의 `SlagWatch` 폴더와 병합합니다.
3. 겹치는 `app.py`만 G3 통합 UI로 교체됩니다. 기존 모든 학습 모델과 봉인된 연구 파일은 원본을 유지합니다.
4. `START_WINDOWS.cmd`를 실행하고 **슬래그 G3 개선 실험** 화면을 선택합니다.
5. 자세한 사용법과 성능 제한은 `README_SLAG_G3_KO.md`를 참조합니다.

패치만으로 단독 실행할 수 없습니다. 독립 설치가 필요하면 **G3 완전 통합본**을 받으세요.
