# 별도 패치 ZIP 설치 방법

- 가장 간단한 방법은 **완전 통합 ZIP**을 새 폴더에 풀고 `SlagWatch/START_WINDOWS.cmd`를 실행하는 것입니다.
- 기존 `SteelTrust_G1_UI.zip`을 이미 설치했다면 **패치 ZIP**을 해당 프로젝트의 **상위 폴더**에 풀어 `SlagWatch/` 아래 파일이 합쳐지도록 하세요.
- 겹치는 파일은 `app.py`, `app_demo.py`, `start_demo.py`뿐입니다. 봉인된 기존 연구 파일과 가중치 파일은 덮어쓰지 않습니다.
- 패치는 원본 G1 ZIP의 데이터·가중치 파일이 필요합니다. **패치 ZIP만으로 단독 실행할 수 없습니다.**
- 신규 메인 메뉴: `Adaptive Red Team`.
- 자세한 문서: `SlagWatch/README_ADAPTIVE_REDTEAM_KO.md`.
