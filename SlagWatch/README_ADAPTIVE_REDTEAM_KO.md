# SteelTrust G2 — Adaptive Red Team 통합 사용설명서

> **연구용 시제품**. 기존 G1, V0/V1/V2, K0/K1, CNN 및 SSFD 기준 모델의 학습 가중치를 변경하지 않습니다.
> Adaptive Red Team의 탐색 결과는 **개발·검증 데이터로부터 얻은 탐색적 결과**이며,
> 실제 제철소에서의 안전성 또는 새로운 독립 테스트셋의 성능 보증이 아닙니다.

## 1. 이번 배포의 구성

- 기존 `SteelTrust_G1_UI.zip` 전체와 전달받은 다섯 모델 ZIP의 파일을 확인한 뒤 통합했습니다.
- 이미 프로젝트에 포함된 G1 / V0·V1·V2 / ResNet18 / CNN / artifacts 파일과 새 ZIP의 동일 경로 파일 **총 72개 파일이 바이트 단위로 같음**을 확인했습니다. K0·K1 패키지는 새 `experiments/inspection_binary/`에 원본 그대로 추가했습니다.
- 기존 봉인된 G1 연구 스크립트와 `manifest.json`은 그대로 유지했습니다. `app_demo.py`, `app.py`에 신규 메뉴 라우팅만 추가하고 `src/adaptive_*.py` 파일을 별도로 만들었습니다.
- 로컬 실시간 분석 대상: **강판 분류 V0, V1, V2, G1 / 슬래그 진동 C0, C1, A1, J**.
- **K0, K1**은 데이터의 정합성 및 모델 헤드 로드만 검증합니다. KSDD2의 공식 원본 이미지·마스크가 이번 ZIP에 없어서 적절한 정상·불량 신규 검증을 수행할 수 없습니다.
- `artifacts`의 폴드별 모델은 원래 슬래그 진동 실험의 비교 기준으로 보존합니다. 신규 능동 탐색에서 직접 제어하거나 변경하지 않습니다.

## 2. Windows 실행

1. 압축을 **하나의 폴더에 전체 해제**합니다. 실행 파일은 `SlagWatch/START_WINDOWS.cmd`입니다.
2. 기존처럼 Python **3.11 64비트**가 필요합니다. 최초 실행에는 패키지 설치를 위한 인터넷 연결이 필요할 수 있습니다.
3. 브라우저의 메인 왼쪽 메뉴에서 **Adaptive Red Team**을 선택합니다.
4. `강판 결함 AI 능동 탐색`에서는 V0, G1, V1, V2 중 모델을 선택하고, validation 이미지의 샘플 ID, 탐색 예산(이미지당 8~60회), 난수 시드를 지정합니다.
5. **실제 모델로 Adaptive Red Team 실행** 버튼을 누릅니다. 모델을 호출한 결과를 보여주며, 원본부터 오분류한 이미지는 유발 오류 분모에서 제외합니다.
6. `진동 AI 능동 탐색`에서는 C0, C1, A1, J와 SSFD 파일/0.5초 구간을 선택합니다. 해당 그룹을 학습하지 않은 outer-fold 체크포인트로 실제 추론합니다.
7. `전체 모델 검증 기록`에서 봉인된 모델 파일과 실험 스크립트의 SHA-256 검사 결과를 확인합니다.

### CLI: 화면 없이도 실행 가능

`SlagWatch` 디렉터리 안에서, 동일 가상환경의 Python으로:

```powershell
python -m src.adaptive_cli audit --out adaptive_runs/audit.json
python -m src.adaptive_cli surface --model V0 --samples Cr_1 --budget 24 --warmup 8 --out adaptive_runs/surface.json
python -m src.adaptive_cli signal --model C1 --file S-4.csv --window 0 --budget 24 --warmup 8 --out adaptive_runs/signal.json
python -m pytest -q tests/test_adaptive_redteam.py
```

`Cr_1` 및 `S-4.csv`는 이번 파일에서 확인한 예시입니다. 원본부터 틀린 예시의 경우 검색을 생략하고 기록합니다.

### 결과 파일

- `adaptive_redteam_results.json`: 모델 ID·파일 해시·난수·입력 해시·교란 조건·각 시험의 오분류 및 결정 점수
- `adaptive_redteam_summary.csv`: 이미지별 탐색 성과 요약
- `adaptive_redteam_trials.csv`: 시험별 입력 조건·결정 결과
- `adaptive_signal_results.json`: 진동 탐색의 fold·실제 모델 점수·판정·시험별 결과
- `adaptive_model_audit.json`: 파일 정합성 확인 및 모델 채택 상태

UI에서 직접 내려받거나 CLI `--out` 경로에 저장할 수 있습니다. ZIP에는 일부 실행 예시도 포함합니다.

## 3. Adaptive Red Team 알고리즘

**이름에 포함된 Adaptive의 정확한 의미**는 다음과 같습니다.

- 첫 `warmup`회 시험은 기준 비교를 위해 동일한 난수 조건에서 무작위로 선택합니다.
- 이후부터 `RandomForestRegressor`를 **현재 시험에서 관찰한 모델의 결정 점수·오분류 결과**로 학습합니다.
- 아직 사용하지 않은 교란 후보 128개를 생성하고, 대리모델의 예상 실패 점수 + 불확실성 + 새로운 조건 탐색 보너스를 비교하여 다음 시험을 고릅니다.
- 같은 시험 예산의 순수 무작위 탐색을 함께 수행하며, 발견된 오류의 수, 첫 오류 발견까지의 시도 수, 가장 작은 교란의 크기를 기록합니다.
- 강판 영상: 가우시안 잡음, 밝기, 대비, 블러. 안전장치로 RMSE <=0.18, 밝기 포화 픽셀 비율 <=0.18을 적용합니다.
- 3축 진동: 상대 잡음, 전체 이득, 순간 충격, Y축 이득. 상대 RMSE <=0.55를 적용합니다.

이것은 **학습형 탐색기(머신러닝)**이지 심층 강화학습 모델이나 딥러닝 기반 FailureNet이 아닙니다. 24~60회의 평가 데이터로 거대한 신경망을 성급하게 학습하기보다 재현 가능한 능동 탐색으로 시작했습니다.

**주의:** RMSE와 포화 비율은 이미지의 물리적/의미적 정답이 보존됨을 증명하지 못합니다. 사람이 결함 유지 여부를 검토하지 않았다면 '후보 취약 조건'으로만 보고해야 합니다.

## 4. 연구 규율 및 데이터 누수 방지

- NEU-CLS: **validation 분할만** 신규 취약 조건 탐색에 사용합니다. 이 기능은 G1의 동결 test 결과를 열지 않습니다.
- SSFD: 기존 그룹 교차검증에서 평가된 **out-of-fold 그룹만** 사용하지만, 그 결과를 반복 활용해 탐색하기 때문에 **새로운 독립 시험으로 간주할 수 없습니다.**
- 모델 개선 효과를 새로 주장하려면 별도 보지 않은 원본 이미지·신규 설비/카메라/운전 조건을 독립 시험용으로 확보해야 합니다.
- 실험 중 기본 모델, G1, K0/K1, CNN의 가중치를 갱신하거나 자동 채택하지 않습니다.
- 무작위 탐색 대비 adaptive 개선은 고정된 시드 하나의 결과가 아닌 여러 이미지·여러 시드에서 검정해야 합니다.

## 5. 현행 모델 개선 우선순위

1. **K1 (우선 개선 필요 / 채택 금지):** 불량 미검출 증가로 기존 선정 기준을 통과하지 못했습니다. 모델 임계값을 사후에 조정해서 시험 결과를 포장하면 안 됩니다. KSDD2 원본·마스크를 가져와 별도 개발 분할에서 불량 recall 하한을 먼저 설정해야 합니다.
2. **CNN C0/C1 (우선 개선 필요 / 채택 금지):** 원본 검출률이 낮고 오경보율이 높습니다. 데이터/속도/센서 분포 변화, 파일·그룹 분리, loss/임계값/특징 추출법을 다시 검토해야 합니다.
3. **V1/V2 (채택 보류):** 일부 교란에서 성능이 좋아졌지만 원래 검증 규칙상 실패했습니다. 기준 모델을 덮어쓰지 않고 후보로만 유지합니다.
4. **G1 (채택 가능, 현장 적용 아님):** 가우시안 잡음 성능 개선을 재현했으나 원본 정확도는 359/360에서 357/360으로 감소했습니다. 밝기, 흐림, 새 카메라 등 미사용 조건을 반드시 검증해야 합니다.
5. **V0/ResNet18/기존 artifacts:** 성능 비교를 위한 고정 기준으로 유지합니다. NEU-CLS는 모두 결함 영상이라 정상/불량 식별 능력을 갖췄다는 뜻은 아닙니다.

## 6. 남아 있는 검증 제한

- 실제 KSDD2 원본 이미지/마스크가 없어 K0/K1 신규 추론의 정확도는 측정하지 않았습니다.
- 이 환경에는 Streamlit이 설치되지 않아 **브라우저 UI 동작은 직접 실험하지 못했습니다.** 대신 파이썬 컴파일, CLI 추론, 봉인된 모델 실행, 신규 단위 테스트, 기존 핵심 회귀 테스트를 수행했습니다.
- 기존 프로젝트는 Python 3.11 패키지 잠금을 요구합니다. 이번 정적/모델 테스트는 제공 환경의 Python 3.13에서 수행한 것이므로 Windows 3.11 초기 설치 확인이 추가로 필요합니다.
- 공개 원본의 산업적 현장 적합성/실제 사고 감소 효과는 아직 검증되지 않았습니다.

**안전 주의:** G2는 검사 AI의 오류 가능성을 분석하는 연구 시연용이며, 실제 제철소 설비 정지나 산업 안전 PLC를 직접 제어해서는 안 됩니다.
