# SteelTrust G7 — 통합 AI 모델 신뢰성 검증 프로그램

## 1. 프로그램 소개

SteelTrust는 철강 결함 탐지 모델 자체가 아니라 **이미 학습된 산업용 AI의 취약점을 탐색하고, 개선 전후 성능을 검증하는 연구용 통합 플랫폼**입니다. G7은 기존 표면 결함 G1, 표면 이진 K0/K1, Adaptive Red Team, G3R 및 다른 슬래그 모델을 유지하면서, **G5-B / G6-B / G6 Deep의 동등한 시험 구간 평가**를 메인 화면에 추가했습니다.

- 기존 **NEU-CLS 표면 결함 분류**: V0/V1/V2 및 개선 G1, 오분류와 개선 후 새 오류
- **정상·불량 검사**: K0/K1의 저장된 검증 기록 (KSDD2 원본 영상은 포함되지 않음)
- **슬래그 진동 이전 모델**: A1, J, CNN C0/C1, G3R (기존 연구 메뉴)
- **동일 프로토콜 신모델 비교**: G5-B SVM, G6-B ExtraTrees, G6 Residual MLP
- **Adaptive Red Team**: 사전 정의 교란 + Random Forest 대리모델을 통한 시험 조건 능동 선택

**모든 모델은 연구용입니다. 공정 자동 정지나 인명 안전 제어에 사용하지 마세요.**

## 2. Windows / Python 3.12 실행

1. 전체 ZIP을 적당한 폴더에 압축 해제합니다. 경로에 특수문자 및 매우 긴 폴더명은 피하세요.
2. **64비트 Python 3.12**가 설치되어 있고 Windows의 `py -3.12` 명령을 사용할 수 있는지 확인합니다.
3. `SlagWatch/SETUP_G7_PY312_WINDOWS.cmd`를 한 번 실행합니다. 인터넷이 필요하며, 기존 프로젝트와 충돌하지 않도록 `.venv_g7` 독립 가상환경을 만듭니다. PyTorch CPU 패키지를 기본 설치하므로 NVIDIA GPU가 없어도 분석할 수 있습니다.
4. `SlagWatch/START_WINDOWS.cmd`(또는 `START_G7_WINDOWS.cmd`)를 실행합니다. 브라우저에 메인 **통합 관제**와 **슬래그 G5·G6 모델 검증**이 표시됩니다.
5. 실행이 안 되면 `CHECK_G7_WINDOWS.cmd`로 모델·평가 기록을 검사하고 Windows CMD에 나온 오류 메시지를 확인합니다.

> 기존 `START_G3_LEGACY_WINDOWS.cmd`와 `start_demo.py`는 과거 Python 3.11 실행 환경의 참조본으로 보존했습니다. G7은 독립 실행기를 사용하며 과거 스크립트를 직접 변경하지 않습니다.

## 4. 슬래그 모델의 동일 조건 비교

이 프로그램은 SSFD 16개 출강 그룹에서 B/S 두 상태를 대상으로 **각 그룹 B 5개 + S 10개, 총 240개**의 0.5초 비중첩 구간을 같은 키 `(group, phase, start_s)`로 연결합니다.

- B 단계 5초 중 **처음 2.5초**는 같은 출강의 확인된 B 상태 기준 신호입니다. 이 신호는 평가 구간에서 제외합니다.
- 기준 진동 없이 시작하는 실시간 슬래그 감지 AI가 아닙니다. B 상태가 확실하게 확인돼야 작동합니다.
- 16개 출강 그룹 단위로 학습·시험을 분리한 교차검증 예측(OOF)을 사용합니다.
- 단, **같은 16개 그룹으로 G1~G6을 반복 개발**했으므로, 기록된 성능은 완전히 독립적인 최종 성능이 아닙니다.
- **G3R**은 초기 E 상태 기준 보정 및 400개 별도 평가 구간이므로 B2 표와 합산하지 않습니다.
- **G6 Deep 20개 체크포인트**는 4개 폴드 × 5개 시드로 저장된 평가 모델입니다. 이들을 새 현장용 단일 최종 모델로 취급하지 않습니다.

### 저장 예측 재계산 수치

| 모델 | TP/S | FN/S | FP/B | TN/B | 슬래그 검출률 | 오경보율 | ROC-AUC |
|---|---:|---:|---:|---:|---:|---:|---:|
| G5-B SVM | 81 | 79 | 5 | 75 | 50.63% | 6.25% | 0.755 |
| G6-B ExtraTrees | 86 | 74 | 5 | 75 | 53.75% | 6.25% | 0.789 |
| G6 Deep Residual MLP | 49 | 111 | 7 | 73 | 30.63% | 8.75% | 0.694 |

G6-B가 G5-B보다 근소하게 좋았으나 새로 고친 오류와 새로 만든 오류가 있으므로 독립 현장 검증 없이 채택할 수 없습니다. G6 Deep은 현재 G6-B보다 열세입니다.

### 새 실측 CSV 분석

`슬래그 G5·G6 모델 검증 → 별도 진동 CSV 분석`에서 다음 두 파일을 입력합니다.

- **B 기준 CSV**: 같은 출강에서 정답 확인된 B 신호 2.5초 이상 (16000행 이상)
- **시험 CSV**: 6400Hz 3축 진동, 최소 0.5초 (3200행 이상)
- **열 이름**: `time,x,y,z` 또는 최소 `x,y,z`; 결측치, 무한대 값은 거부됩니다.
- 출력: G5-B 점수/임계값/판정과 G6-B 점수/임계값/판정이 **같은 진동 창**마다 기록됩니다.
- **학습 데이터와 중복되면 독립 정확도를 측정했다고 주장하면 안 됩니다.** 새 데이터 정답이 없다면 정확도는 계산할 수 없습니다.

CLI 예제 (프로젝트의 `SlagWatch` 폴더에서 실행):

```bat
.venv_g7\Scripts\python.exe -m src.slag_compare_cli check
.venv_g7\Scripts\python.exe -m src.slag_compare_cli report --out reports\g7_reliability_report.json
.venv_g7\Scripts\python.exe -m src.slag_compare_cli predict --reference "data\raw\Steel Slag Flow Dataset (SSFD)\B-1.csv" --target "data\raw\Steel Slag Flow Dataset (SSFD)\S-1.csv" --out reports\g7_example.csv
```

G6-B는 전체 16개 SSFD 기록으로 학습된 최종 연구 모델이며, 위 예제는 **동일 학습 데이터의 기능 시연**입니다. 따라서 보고된 OOF 정확도와 혼동하면 안 됩니다. `.joblib`은 피클 기반 파일이므로 제작자가 확인된 파일만 열어야 합니다.

## 5. SteelTrust 자체 모델의 기술적 평가

**잘된 부분**

1. 모델의 기존 오류뿐 아니라 **개선 과정의 신규 오류**를 따로 기록합니다.
2. 표면 결함 분류기에서 실제 교란 검증과 고정된 시험 기록이 있습니다.
3. Adaptive Red Team의 Random Forest 대리모델이 시험 횟수 예산 내 탐색 조건을 선택합니다.
4. 이미지와 진동을 혼동하지 않고 각각의 정답 및 평가 지표를 분리합니다.
5. 모델 교체는 최소한 기존 모델과 같은 샘플, 같은 검증 조건에서 비교합니다.

**보완할 부분**

1. SteelTrust 자체는 **단일 범용 딥러닝 모델이 아니라 실험·통계·머신러닝 기반 프레임워크**입니다.
2. Adaptive Red Team의 발견 효율이 무작위 탐색보다 좋은지, 미사용 데이터에서 정량 검증이 필요합니다.
3. 실제 환경에서 교란이 원래 정답을 유지하는지 검증할 필요가 있습니다.
4. 원본 이미지와 파생 변형이 학습/검증/시험을 넘나들지 않도록 분리해야 합니다.
5. SSFD 출강 조건이 적고 반복 모델 개발에 쓰였으므로 **새 출강 작업을 확보한 외부 검증**이 필요합니다.
6. 긴 진동에서 지속 오경보와 미검출, 실제 운영 상황의 B 기준 확보 문제를 해결해야 합니다.
7. 현재의 모든 슬래그 모델은 산업용 자동 차단 기준을 통과하지 못했습니다.

## 7. 기술적 제한 및 검증 상태

- 확인됨: CSV 240×3 모델의 1:1 키 일치, 예측/임계값 재계산, G5/G6B 실측 예시 추론, 원본 모델/실험 82개 해시 일치.
- 확인됨: 신규 테스트 9개 및 현재 환경에서 실행 가능한 핵심 회귀 테스트.
- 제한: 검증 환경에 Streamlit·aeon이 없어 **실제 브라우저 UI 구동 검사는 수행하지 못했습니다.**
- 제한: 기존 Python 3.11 전용 설치기의 일부 테스트는 현재 Python 3.13 환경에서 실행할 수 없습니다. 새 Python 3.12 설치기는 Windows에서 재검증이 필요합니다.
- 미검증: G6 신규 딥러닝 모델의 실제 현장 성능, 외부 제철소 출강, 10시간 이상 추가 학습의 향상 효과, 산업 안전 검증.

**연구용 판정:** 표면 결함 G1은 이전 실험 기준 통과 기록을 보존합니다. G6-B는 **연구용 비교 기준**으로 유지합니다. G6 Deep은 기존 G6-B에 열세이므로 자동 채택하지 않습니다.
