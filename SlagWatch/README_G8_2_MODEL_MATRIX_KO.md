# SteelTrust G8.2 — 전체 모델 비교·개별 검증 UI

> 기존 G8.1의 POSCO 로고와 밝은 Dohyeon 스타일을 유지하면서 **모델별 검사 / 한눈에 비교 / 두 모델의 새 오류 비교**를 추가한 UI 개편판입니다.
> 기존 학습 가중치·시험 점수·임계값·기존 봉인 평가 기록은 **전혀 변경하지 않습니다**.

## 1. 설치

**G8.1이 이미 실행되는 Windows PC**라면 작은 `SteelTrust_G8_2_ModelMatrix_Patch.zip`만 받으면 됩니다.

1. 실행 중인 SteelTrust 터미널에서 `Ctrl+C`를 눌러 종료합니다.
2. 기존 SteelTrust 폴더를 백업합니다.
3. 패치 ZIP을 해제하면 `SlagWatch` 폴더가 나옵니다. 기존 `SlagWatch`가 들어 있는 **상위 폴더**에 복사하여 덮어씁니다. `SlagWatch/SlagWatch`처럼 폴더를 중첩하면 안 됩니다.
4. 기존 `SlagWatch/START_WINDOWS.cmd`로 실행하고 브라우저에서 `http://127.0.0.1:8501`을 엽니다.
5. 문제가 있으면 `SlagWatch/CHECK_G8_WINDOWS.cmd`를 실행해 테스트 결과를 확인합니다.

Python 3.12 환경이 없는 신규 설치라면 완전 통합본을 사용하고 `SETUP_G8_PY312_WINDOWS.cmd`를 먼저 실행하세요.

## 2. 무엇이 달라졌나요?

좌측 메뉴는 **시작하기 / 금속 표면 / 슬래그 / 취약점 검사 / 도움말**로 줄였습니다. 첫 화면에서는 세 가지 작업 중 하나를 골라 이동합니다.

### 금속 표면

`표면 결함 6종 분류`와 `정상·불량 검사`를 화면 상단에서 선택합니다.

- **전체 모델 비교:** V0·V1·V2·G1 4개 모델의 원본/잡음 성능 차트와 잡음 강도별 정확도를 한눈에 표시합니다.
- **모델 개별 확인:** 원하는 모델을 하나 선택해 정확도, 실패 이미지, 클래스 혼동 행렬을 봅니다. **원본 강판 이미지**도 확인할 수 있습니다. (잡음 입력 예측의 원본 이미지임을 명시)
- **두 모델 비교:** 같은 이미지·잡음 시드에서 복구된 오답·새 오답·둘 다 틀린 경우를 계산합니다. V0→G1의 공식 사례 재추론 및 ZIP 저장 기능도 남겼습니다.
- **정상·불량 검사:** K0/K1의 불량 검출률, 오경보율, 미검출·새 오류를 같은 Validation 기록으로 비교합니다.

**중요: V0/V1/V2/G1 4종 전체 공통 비교는 Validation 3,600개 예측에서만 가능합니다.** V0/G1만 별도의 Test 3,600개 예측을 비교할 수 있습니다. Validation은 개발 과정에 사용된 자료이므로 공식 외부 성능으로 오인하면 안 됩니다.

### 슬래그

**8종** A1, J, C0, C1, G3R, G5-B, G6-B, G6 Deep의 모든 모델을 선택할 수 있습니다.

- **전체 8종 한눈에:** 3개 평가 그룹으로 분리해 그래프를 그립니다.
- **개별 확인:** 검출률, 오경보율, 미검출 수, 출강 그룹별 성능, 혼동 행렬과 오분류 구간을 봅니다.
- **두 모델 비교:** 같은 평가 그룹 안에서 2개 모델을 골라 개선 오류 수/신규 오류 수와 성능을 비교합니다. 비교 결과는 CSV로 저장할 수 있습니다.
- **연구용 CSV 추론:** G5-B와 G6-B만, 동일 출강에서 **정상 B 단계가 확인된 기준 CSV**가 있을 때 사용 가능합니다. G6 Deep의 교차검증 체크포인트를 실측 모델처럼 실행하지 않습니다.

동일하지 않은 시험을 한 모델을 한 줄의 단일 순위로 정렬하는 것은 잘못된 비교이므로 차단했습니다.

| 평가 그룹 | 비교 가능한 모델 | 평가 구간 | 기준 상태 |
|---|---|---:|---|
| 기초 진동 | A1 / J / C0 / C1 | 480 | E·B·S, 0.5초 |
| E 기준 | J / G3R | 400 | E 기준 보정, J의 동일 구간 추출 |
| B 기준 | G5-B / G6-B / G6 Deep | 240 | B 기준, B/S 이진 분류 |

J는 평가 방식이 다른 **두 그룹에 반복 표시**되며 중복 모델로 세지 않습니다.

## 3. 검증한 값 (저장된 예측값 기준)

| C1 | 480 | 23.75% | 22.19% |

비교 분모가 다른 그룹끼리는 순위를 매기지 마세요. 저장된 데이터는 **기존 SSFD의 출강 조건 16개**를 반복 연구한 결과이며 실제 신규 제철소에서의 평가가 아닙니다.

V0/G1의 별도 Test 3,600회 판단에서 잡음 조건 오답은 각각 **460 / 50회**입니다. 잡음 조건만 비교하면 복구 **418회**, 신규 오류 **8회**였습니다(원본에서 발생한 새로운 오류는 별도).

## 4. 오류 검증 범위

- 신규 모델 카탈로그 테스트, G8 화면 로직 테스트 및 기존 G8/슬래그/Adaptive Red Team 핵심 테스트 통과
- 기존 봉인 연구 파일 SHA-256 검사 **82건 중 실패 0건**
- Python 소스 컴파일 성공, ZIP 무결성 검증
- 실제 모델 예측 **기존에 저장된 평가 기록에 대한 재계산**이며, 이 버전에서 모든 모델을 신규로 재학습한 결과가 아닙니다.
- 테스트 환경에 Streamlit·aeon이 없어 **Windows 브라우저에서의 최종 렌더링은 미검증**입니다. 새 화면은 Streamlit-free 모의 UI 스모크 테스트로 데이터 렌더링 경로를 검사했습니다.

## 5. 보안 및 유의사항

임의 `.joblib`/`.pt` 파일을 웹에서 업로드받아 실행하지 않습니다. 학습 가중치는 기존 배포본의 신뢰한 파일만 사용합니다. **산업 현장 자동 슬래그 차단·품질 합격 판정·안전 제어에 사용하지 마세요.**

POSCO 로고는 브랜드 참조 목적의 시연용이며, 공식 승인·후원 표기가 아닙니다.
