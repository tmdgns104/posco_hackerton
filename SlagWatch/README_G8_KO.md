# SteelTrust G8 간편 통합판 — 처음 사용하는 분을 위한 안내

## 먼저 알아야 하는 점

SteelTrust는 결함을 발견하는 AI 하나가 아니라 **기존 산업용 AI가 틀린 조건을 찾고, 기존 모델과 후보 모델을 같은 데이터로 비교하는 검증 프로그램**입니다. 모델 가중치와 이전 평가 기록은 **변경하지 않았습니다**.

이 버전은 G7의 **14종 모델 계열과 기존 실험 기록을 그대로 보존**하고, 메인 화면만 신규 `app_easy.py`로 교체한 버전입니다. 기존 `app_demo.py` 및 연구 모듈들은 삭제하지 않았습니다.

### 어떤 코드의 장점을 사용했나?

- **기존 G7**: 슬래그 동일 구간 240개 비교, G5-B/G6-B/G6 Deep, SSFD B 기준 연구 추론, 기존 G1 실험, Random Forest 능동 Red Team, 실험 파일 해시 감사
- **GitHub `tmdgns104/posco_hackerton`의 `dohyeon` 브랜치 공개 소스에서 확인한 방식**: 모델 교체 시 **복구한 오류와 새 오류를 동시에 보여주는 사용자 흐름**, 정상·불량 미검출/오경보 구분, **동일 사례 재검증·ZIP 저장**의 중요성, 모델 검증 기록을 유지하는 원칙
- 이번 버전에서는 **직접 확보한 G7의 평가 CSV와 원본 모델을 이용해 새 간편 UI 및 K0/K1 교체 비교 화면**을 직접 구현했습니다. GitHub 브랜치 전체 소스와 원본 KSDD2 이미지를 내려받아 그대로 병합한 것은 아닙니다. GitHub의 임의 모델 업로드·로그인·원격 감사 서버 등은 포함되지 않습니다.

## 1. Windows 설치와 실행

1. Python 3.12 **64비트**를 설치합니다.
2. 전체 ZIP을 폴더에 모두 압축 해제합니다. (예: `Documents\SteelTrust_G8`)
3. `SlagWatch\SETUP_G8_PY312_WINDOWS.cmd`를 **한 번** 실행합니다. 첫 설치에는 인터넷이 필요합니다.
4. `SlagWatch\START_WINDOWS.cmd`를 더블클릭합니다.
5. 브라우저에서 `http://127.0.0.1:8501`을 열면 됩니다. 콘솔은 끄지 마세요.
6. 처음 실행 시 Streamlit 이메일 안내가 뜨면 비워둔 채 Enter를 누릅니다. Streamlit 사용 통계 전송은 비활성화했습니다.

> G8 UI 기본 설치는 CPU 지원 PyTorch를 사용합니다. RTX 4070 Mobile이 있어도 검증 화면에는 GPU가 필수 아닙니다.

## 2. 다섯 화면을 이렇게 사용하세요

| 화면 | 처음 보는 분이 할 일 | 의미 |
|---|---|---|
| **시작하기** | 원하는 분야의 버튼 클릭 | SteelTrust의 목적과 세 개의 핵심 평가 소개 |
| **강판 결함** | 기본값 '잡음 조건' 확인 → 바로잡은 오류/새 오류 선택 | V0 vs G1에서 잡음에 따른 강건성 개선과 부작용 |
| **정상·불량** | K0와 K1의 불량 미검출·오경보 비교 | K1의 오경보 감소가 새 미검출을 정당화하지 않음 |
| **슬래그** | 기존 모델과 후보 모델을 선택 | 같은 B/S 240구간의 미검출·오경보·오류 변화를 직접 비교 |
| **취약점 검사** | V0 또는 G1과 빠른/정밀 선택 → 검사 시작 | 교란 시험으로 오분류 조건 탐색, 모델 변경 없음 |
| **도움말** | 필요한 때만 사용 | 모델 등록부, 이전 G7 메뉴·파일 해시 검사 |

**표·CSV·모델 해시·폴드별 세부 기록은 기본적으로 접혀 있습니다.** 필요할 때만 확장하세요.

## 3. 기록에서 확인되는 결과 (새 학습 결과가 아닙니다)

### 강판 결함 V0 → G1

- NEU-CLS 표면 6종 분류 · 잡음 9조건/총 3,240회 반복 평가
- **기존 V0 오류 460회 → 개선 G1 50회**
- 기존 오답을 바로잡은 횟수 **418회**, 새로 생긴 오답 **8회**
- 원본 360장의 경우, V0 오류 1회 → G1 오류 3회 (**원본 성능 하락**)
- 동일 이미지를 여러 번 변형한 결과는 독립 이미지 개수로 해석하지 않습니다.

### 정상/불량 K0 → K1

- KSDD2 검증 원본 466장에 7조건을 적용한 **3,262회 평가**
- 불량 미검출 **48 → 76회** (악화)
- 정상 오경보 **601 → 263회** (개선)
- 따라서 **K1 자동 채택 보류**. 공식 KSDD2 시험 데이터 성능을 주장하지 않습니다.
- 이 G7 출처 패키지에는 KSDD2 원본 이미지가 없어 직접 이미지 재추론 화면을 표시하지 않습니다.

### 슬래그 B/S 구간 분류

| 모델 | 슬래그 검출 | 비슬래그 오경보 | 미검출 |
|---|---:|---:|---:|
| G5-B SVM | 81/160 (50.63%) | 5/80 (6.25%) | 79 |
| G6-B ExtraTrees | 86/160 (53.75%) | 5/80 (6.25%) | 74 |
| G6 Deep MLP | 49/160 (30.63%) | 7/80 (8.75%) | 111 |

G6-B는 연구용 비교에서는 가장 낫지만 **슬래그 미검출이 여전히 매우 많습니다**. 새로운 제철소 데이터에서 확인되지 않았고 실제 자동 차단용으로 승인되지 않았습니다.

## 4. 기존 G7의 전문 메뉴

별도 `SETUP_G7_PY312_WINDOWS.cmd`로 기존 G7 환경을 설치하고, `START_G7_LEGACY_WINDOWS.cmd`를 실행하면 이전의 상세 연구 화면을 8502 포트로 열 수 있습니다. 두 환경은 독립적입니다.

## 5. 오류가 날 때

- **브라우저에 페이지가 안 뜸:** 콘솔이 `Welcome to Streamlit / Email:`에서 대기 중이면 Enter를 누릅니다. 접속 주소 `http://127.0.0.1:8501` 확인.
- **포트 충돌:** 다른 Streamlit이 8501을 이미 사용 중인지 확인합니다. 다른 프로세스를 임의로 종료하지 말고 해당 창을 닫거나 포트를 변경하세요.
- **Python 3.12 없음:** PowerShell에서 `py -3.12 --version` 확인.
- **모델 누락:** 전체본 ZIP을 다시 정상 압축 해제하세요. 패치 ZIP만으로는 모델이 없습니다.
- **검증 명령:** `SlagWatch\CHECK_G8_WINDOWS.cmd`를 실행하세요.
- **인터넷 연결이 제한됨:** 첫 환경 설치 시에만 필요하며, 이미 동봉된 모델을 읽는 데 클라우드 호출은 하지 않습니다.

## 6. 기술적 검증 범위와 안전

- 새 핵심 로직은 `tests/test_g8_easy_core.py`에 있는 검사를 통해 데이터 짝짓기, 진단 오류, 요약 지표와 평가 범위 혼동을 탐지합니다.
- **모델의 `.joblib`은 코드 실행을 포함할 수 있으므로 출처가 확인되지 않은 파일의 웹 업로드·즉시 실행은 제공하지 않습니다.**
- 현장 자동 제어, 신규 모델 자동 교체, 외부 데이터에서의 정확도 보증, 능동 탐색 자체의 우월성 보증은 구현하거나 주장하지 않습니다.
- 이 환경에서 Windows·Streamlit 브라우저 화면의 실제 구동까지는 시험하지 못했습니다. Windows 실행 후 `CHECK_G8_WINDOWS.cmd`로 모델 기록을 검증하고 첫 실행을 확인하세요.
