# SteelTrust G3 — 슬래그 진동 감지 개선 실험 (SSFD)

작성 기준: 2026-11-09 · G2의 기존 모델/봉인된 결과를 변경하지 않고 추가했습니다.

## 시작하기

1. 기존과 동일하게 `START_WINDOWS.cmd` 실행 → 왼쪽 메뉴 **슬래그 G3 개선 실험**.
2. **개발 평가**: 외부 그룹을 제외해 점수화한 모델별 결과와 오경보·미검출을 확인합니다.
3. **홀드아웃 구간 검토**: 출강 그룹 1~16과 E/B/S를 선택해, 그 그룹을 학습하지 않은 fold의 저장된 예측을 검토합니다.
4. **외부 CSV 분석**: 동일 출강 작업의 초기 무슬래그 진동 CSV와 대상 CSV 두 개를 업로드합니다. `time,x,y,z` 열, 6400Hz, 0.5초(3200행) 정수배의 진동 기록이 필요합니다. 먼저 기준 신호가 실제로 무슬래그였음을 확인해야 합니다.
5. **현장 안전 제어/실제 자동 정지에 연결하지 마세요.** 슬래그 검출 재현율이 아직 낮으며 새로운 현장 검증이 없습니다.

## 명령줄 실행

Windows 가상환경이 이미 준비된 경우 프로젝트 폴더에서:

```powershell
.venv\Scripts\python.exe -m src.slag_g3_aug predict --reference "data/raw/Steel Slag Flow Dataset (SSFD)/E-1.csv" --target "data/raw/Steel Slag Flow Dataset (SSFD)/S-1.csv" --fold 3
```

그룹 1은 fold 3의 학습에서 제외되어 예시가 *그룹 홀드아웃 추론*이 됩니다. `--fold 3`을 제거하면 전체 16개 그룹에 학습한 배포용 파일을 사용하므로 SSFD 자체를 대상으로 한 결과를 독립 검증이라고 부를 수 없습니다.

```powershell
.venv\Scripts\python.exe -m src.slag_g3_aug train
```

위 학습 명령은 데이터 검증부터 중첩 그룹 CV, Gaussian 잡음 증강, 신규 모델 파일·평가 CSV 저장까지 수행합니다. 이미 생성된 모델·평가 파일을 포함했으므로 일반 사용에는 재학습이 필요하지 않습니다. **동일 Python/패키지 버전에서 재현**해야 하며, ExtraTrees의 성능은 환경에 따라 세부 수치가 달라질 수 있습니다.

Linux 실행 예:

```bash
python -m src.slag_g3_aug predict --reference 'data/raw/Steel Slag Flow Dataset (SSFD)/E-1.csv' --target 'data/raw/Steel Slag Flow Dataset (SSFD)/S-1.csv' --fold 3
```

## 실험 데이터와 평가 정의

- 첨부 SSFD는 E-1~E-16, B-1~B-16, S-1~S-16의 총 **48개 파일**, 각 5초(32000 샘플), 3축, 6400Hz입니다.
- E = Early No Slag, B = Before Slag Flow, S = During Slag Flow.
- 서로 연관된 E/B/S 세 파일은 동일 출강 ID(1~16)에 속하므로 0.5초 구간 단위로 무작위 train/test 분할하지 않습니다.
- **사전에 무슬래그라고 확인된 각 출강의 E 첫 2.5초(5개 창)**를 기준 신호로 사용합니다. 이 80개 창은 평가에서도 제외합니다. 이후 E 80개, B 160개, S 160개, 총 **400개 구간**을 평가합니다.
- 4-fold GroupKFold: 테스트 그룹은 학습에서 제외. 각 학습 그룹 안에서 다시 3-fold 그룹 분리로 판정 임계값을 선택해, 테스트 정답이 임계값 선택에 들어가지 않습니다.
- G3R의 입력은 기존 `robust36` + `fine_spectrum` 특징 228개에서 같은 출강의 E 기준 특징 중앙값을 뺀 벡터입니다. ID/파일명/라벨은 분류 특징에 포함하지 않습니다.
- ExtraTreesClassifier, 180개 트리, 최소 leaf=6, `class_weight=balanced`; **학습 그룹의 clean + 잡음 σ=0.02/0.05 데이터로 학습**하며, Gaussian 잡음 추가 시 원본의 S/B/E 라벨을 유지합니다.
- 그룹별 inner OOF clean + σ=0.05에서 FP 비율 15% 상한으로 임계값 보정. 실제 outer test FPR이 15% 이하로 보장되지는 않습니다.
- 합성 시험: clean, gain 0.85, σ=0.05 Gaussian noise(학습에 사용한 잡음 계열), σ=0.08(학습 범위를 벗어난 강도), X축 8샘플 충격. 시험 도중 **E 기준은 원본으로 유지**하는 조건이므로 기준 센서 자체가 고장 났을 때의 성능은 검증하지 않았습니다.

## 모델 비교 (원본 clean · 같은 400구간)

| 모델 | S 검출 / 160 | S 미검출 / 160 | 오경보 / 240 | 오경보율 |
| --- | ---: | ---: | ---: | ---: |
| 기존 J (G2) | 49 | 111 | 41 | 17.08% |
| G3R | **64** | 96 | **29** | **12.08%** |

- G3R 검출률 40.0% / ROC-AUC 약 0.759, 기존 J 검출률 30.6%. **두 모델의 입력 이용 조건은 다릅니다:** G3R은 동일 출강 초기 2.5초의 무슬래그 기준이 필요하고, J는 그렇지 않습니다.
- G3R은 기존 J보다 추가로 36개 S를 검출했지만, 반대로 기존 J가 검출한 S 중 21개를 놓쳤습니다. 오경보 38개를 제거했지만 새 오경보도 26개 생겼습니다. 단순히 모든 사례에서 좋아졌다는 뜻은 아닙니다.
- 원본 이전 실험 기록과 같은 SSFD를 여러 모델 후보의 개발에 사용했기 때문에 **새로운 독립 시험셋 성능이 아니며, 모델 선택 후 낙관 편향이 존재**합니다.

## G3R 자체의 스트레스 평가 (400구간씩)

| 입력 | TP | FN | FP | TN | 검출률 | 오경보율 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 원본 | 64 | 96 | 29 | 211 | 40.0% | 12.1% |
| 이득 0.85 | 67 | 93 | 27 | 213 | 41.9% | 11.3% |
| Gaussian noise σ=0.05 | 69 | 91 | 31 | 209 | 43.1% | 12.9% |
| Gaussian noise σ=0.08 | 73 | 87 | 46 | 194 | 45.6% | 19.2% |
| X축 충격 | 65 | 95 | 29 | 211 | 40.6% | 12.1% |

**상대적 개선과 현장 적합성은 다릅니다.** 슬래그 미검출이 96/160로 매우 많습니다. 이를 안전중요 자동 차단 장치로 사용하는 것은 부적절합니다. 출강 그룹별로 오경보가 집중되어 일부 출강에서는 잘못된 경보가 연속으로 나올 수 있습니다.

## 모델 선택과 앙상블 검토

- 새 clean-only `R36F` / `F192` 후보를 먼저 학습했으나 σ=0.05 합성 잡음에 FP가 급증했습니다. 이 후보들은 비교 실험용으로만 유지했습니다.
- 기존 CNN C0/C1과 기존 J는 **예전 평가 기준에 미달**합니다. 숫자만 평균하는 앙상블로 안전성을 확보했다고 주장할 수 없으므로, 이번 G3에서는 직접 합치지 않고 보존했습니다.
- G3R는 실제 압연/출강 운영에서 요구되는 검출율을 충족하지 않아 **자동 채택하지 않았습니다**. 모델 사용은 개발·시연과 분석에 한정합니다.

## 평가 출력 경로

- `experiments/slag_g3_aug/models/fold_{0..3}_G3R.joblib`: 4개 홀드아웃 그룹 모델.
- `experiments/slag_g3_aug/models/full_G3R.joblib`: 전 데이터 재학습 모델(독립 시험 근거 아님).
- `experiments/slag_g3_aug/predictions.csv`: 각 그룹별 원본/합성 조건·점수·예측.
- `experiments/slag_g3_aug/summary.csv`: 정확한 TP/FN/FP/TN 및 AUC/AP.
- `experiments/slag_g3_aug/inner_cuts.csv`: 폴드별 임계값과 train/test 그룹.
- `experiments/slag_g3_aug/paired_vs_J.csv`: J와 G3R의 동일 창 비교.
- `experiments/slag_g3_aug/run_manifest.json`: 출처 해시·모델 해시 및 실험 제약.
- `experiments/slag_g3/`: clean-only 탐색 후보 2종, 별도 보관.

## 다음 연구에서 필수인 작업

1. **완전히 다른 16회 이상의 출강 기록**으로 독립 검증(가능하다면 제철소·센서별 데이터).
2. 그룹 단위 S 검출율·B 단계 오경보·최초 탐지 지연·무슬래그 기준 오류에 대한 검증.
3. 기준 신호 자체에 잡음·드리프트·센서 위치 변화가 있을 때의 강건성 시험.
4. 새 데이터에서 목표 검출률/오경보율 만족 여부에 따라 모델의 실제 채택을 결정.
5. 상시 센서 기반으로 쓰려면 자동 기준확인, 라벨 시간 해상도 확보, 안전한 중단/작업자 확인 정책이 별도 필요.
