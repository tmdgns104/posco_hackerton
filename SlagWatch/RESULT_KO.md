# SlagWatch v2 개발 결과 | 2026년 11월 7일

공개 철강 주조 진동 SSFD v3에서 슬래그가 흐르는 구간(S)을 찾아내는 모델과 시험 화면을 만들었다. 각 구간은 0.5초이고 양성(S)은 160개, 음성(E/B)은 320개다. 물리적 자료는 16개 번호 그룹에 속한 48개 기록이다. 각 구간의 정답은 소속 파일의 상태 라벨을 따른다.

## 주파수 정보를 더하면 무엇이 달라지는가

기존 Random Forest(RF)는 X·Y·Z축 각각에서 진동의 크기와 변동 폭 등을 나타내는 4개 값, 총 12개 값을 사용했다. v2의 추가 RF에는 축마다 8개 주파수 대역의 상대 에너지를 더했다. 전체 크기가 비슷한 신호도 어느 주파수에 에너지가 집중됐는지 구별할 수 있다.

0.5초 구간에서 평균을 빼고 Hann 창을 곱해 FFT를 적용했다. 6,400Hz 샘플링에서 양의 주파수 간격은 2Hz다. 대역 경계는 2, 25, 50, 100, 200, 400, 800, 1600, 3200Hz이며 각 경계에서 다음 경계 직전까지 합산한다. 최종 대역은 3200Hz를 포함한다. 각 축의 에너지 합으로 나눈 값 24개와 기존 12개 값을 함께 입력했다.

두 RF 모두 트리 100개, 깊이 6, 잎 최소 표본 3개, balanced 클래스 가중치, 난수 42, 판정 기준 0.5를 사용했다. 같은 번호의 E/B/S 파일을 함께 묶고 GroupKFold 4회에 걸쳐 매회 12개 그룹으로 학습하고 나머지 4개로 평가했다. 특징과 임계값을 v2 평가 결과에 맞춰 탐색하지 않았다. 이전 결과를 보고 다음 실험을 설계했으므로 아래 수치는 같은 16개 그룹을 사용한 개발 비교다. 독립적인 최종 시험이나 포스코 현장 평가로 일반화하려면 별도 그룹을 수집해야 한다.

| 원본 480구간 | S 검출 / 160 | 미검출 | E/B 오경보 / 320 | Macro F1 |
|---|---:|---:|---:|---:|
| 단일 RMS 기준선 | 116 (72.5%) | 44 | 267 (83.44%) | 0.341 |
| 진폭 RF | 50 (31.25%) | 110 | 118 (36.88%) | 0.472 |
| 진폭 + 주파수 RF | 69 (43.13%) | 91 | 100 (31.25%) | 0.558 |

원본에서 주파수 RF는 기존 RF보다 슬래그 검출 19개가 늘고 오경보 18개가 줄었다. 실제 양성의 절반 이상은 여전히 놓쳤다. 11번 그룹에서 슬래그 10개를 모두 검출했지만 음성 20개 중 15개에도 경보를 냈다. 8번 그룹에서는 슬래그 10개 전부를 놓쳤다.

## 입력이 달라졌을 때의 주파수 RF

| 조건 | S 검출 | S를 음성으로 판정 | E/B 오경보 | 보류 (S / E·B) | 판정한 구간 |
|---|---:|---:|---:|---:|---:|
| 원본 | 69 | 91 | 100 | 0 / 0 | 480 |
| 잡음 | 69 | 91 | 119 | 0 / 0 | 480 |
| 순간 스파이크 | 96 | 64 | 192 | 0 / 0 | 480 |
| 구간 중앙 누락 | 35 | 45 | 52 | 80 / 160 | 240 |
| X축 값 고정 | 35 | 45 | 52 | 80 / 160 | 240 |

순간 충격을 추가하니 주파수 RF의 오경보가 100개에서 192개(60.0%)로 늘었다. 같은 스파이크 조건에서 기존 진폭 RF의 오경보는 144개였다. 주파수 특징의 원본 성능 개선이 교란 내성까지 보장하지는 않는다. 누락과 값 고정은 분류 전에 공통 입력 검사가 처리했다. 각각 합성 이상이 있는 240개 중 240개가 보류됐고 이상을 넣지 않은 240개 중 보류는 0개였다.

## 앱에서 재현하기

- 미검출 개선 사례 버튼. S-1.csv의 4.5~5.0초에서 진폭 RF 점수는 0.406, 주파수 RF 점수는 0.580이다. 실제 상태는 S다.
- 스파이크 오경보 사례 버튼. B-12.csv의 0~0.5초에 X축 16개 샘플을 교란하면 주파수 RF가 0.469에서 0.559로 경계를 넘는다. 실제 상태는 B다.
- 입력 누락 사례 버튼. B-12.csv의 0번 구간 중 중앙 0.1초가 누락된다. 세 모델 모두 판정을 보류한다. 시험 조건을 원본으로 바꾸면 원래 점수가 복구된다.
