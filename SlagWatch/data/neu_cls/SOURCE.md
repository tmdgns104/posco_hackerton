# NEU surface defect database · NEU-CLS

Kechen Song and Yunhui Yan, Northeastern University. This folder contains the 1,800 original classification BMPs (six hot-rolled steel strip defect categories). File IDs and pixel/file SHA-256 values are recorded in experiments/surface_v1/split_manifest.csv. The original archive was downloaded from the authors' NEU-CLS Google Drive link. All 1,800 packaged BMPs were byte-compared against the downloaded archive. The Windows thumbnail cache was excluded.
