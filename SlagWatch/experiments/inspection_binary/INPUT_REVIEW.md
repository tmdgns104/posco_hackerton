# KSDD2 입력 범위 관찰

공식 train 영역의 실제 RGB/이진 주석 쌍을 확인했다. 개발 학습 분할의 정상 `ksdd2-10000`(229×645)은 빈 마스크, 불량 `ksdd2-10021`(228×649)은 좌상단 경계에 닿는 3,346개 양성 픽셀이다. 공식 학습 구역에 매우 작은 결함도 존재한다. 개발 학습 분할의 `ksdd2-10045`는 7×5 경계 안의 23개 양성 픽셀이다. 중앙 자르기와 정사각형 강제 변형을 피하고 RGB 전경 전체와 원본 비율을 보존한다. 모델의 공간 평균/최댓값은 이미지별로 집계하고 마스크는 입력하지 않는다. 제공받지 않은 코일/제품 그룹이나 실측 결함 크기는 추정하지 않는다.

위 세 학습 이미지의 원본과 강·약 잡음(seed 101), 밝기 0.8·1.2배를 같은 영역에서 원본 픽셀 기준으로 관찰했다. 두 결함의 경계 관련 자국·밝은 점은 원본과 변화 이미지에서 같은 위치에 남았다. 강한 색채 잡음은 세부 질감을 크게 가리며 작은 점은 확인하기가 더 어렵다. 정상의 질감에도 변화가 생겼지만 입력을 자르거나 위치를 바꾸지 않았다. 모든 결함의 사람 식별 가능성을 검증한 것은 아니다. 일곱 조건은 합성 민감도 시험이며 실제 생산 환경에서 허용하는 등급·조명·먼지·진동을 뜻하지 않는다. 주석은 이 육안 확인과 훈련/평가용 정답에만 사용했다. 공식 test 픽셀이나 예측은 모델 설계·선정에 사용하지 않았다.
