# KSDD2 정상/불량 모델 실험

한 장의 표면 영상을 정상/불량으로 판정한다. 인코더 원본은 [PyTorch ResNet18 ImageNet 가중치](https://download.pytorch.org/models/resnet18-f37072fd.pth)이며 SHA-256은 `f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec`이다. 기존 NEU 6종 분류기의 가중치 중 공개 ImageNet ResNet18 인코더만 재사용했다. 기존 NEU 분류 헤드, 예측표와 시험 오류는 사용하지 않았다. 입력은 200×200 회색조가 아니다. 공식 원본 RGB 전체를 비율에 맞게 192×512 안에 넣고 여백을 대칭 반사한다. 전체 공간의 중간·마지막 단계 특징에 평균 및 최댓값 풀링을 적용해 작은 국소 신호도 집계한다. 모든 픽셀을 보고 이미지당 하나의 결정을 내리며 타일이나 변형 이미지를 독립 표본으로 세지 않는다.

**사용 순서:** 시연의 새 실행, 사례 재현, 사례 재시험은 배포된 헤드와 동일 인코더에서 실제 추론한다. 아래 명령은 별도의 선택 사항인 **가중치 재학습**이다. 전체 데이터·정답·분할을 공식 아카이브에서 준비한 후 프로젝트 루트와 설치된 Python 환경에서 실행한다. 이 경로는 공식 test 이미지를 읽지 않으며, 원본 실험의 해시/판정을 덮어쓰지 않는다.

```bash
python -m experiments.inspection_binary.reproduce --out ../ksdd2_retrained --cache ../ksdd2_features
```

실험은 두 단계로 진행되었다. 첫 단계에서 `protocol.json`과 영수증을 저장한 뒤 K0를 학습하고 검증 원본으로 K0 임계값을 골랐다. `K0_validation_diagnostics.csv`로 조건별 실패를 확인하고 원본/변화 영상을 점검하여 `hypothesis.json`에 단 한 후보의 수정 내용을 먼저 저장했다. 그다음에만 K1을 학습했다. K1의 유일한 변경은 각 학습 영상에서 원본과 약·강 잡음(평가와 다른 seed 731), 어두움·밝음 뷰를 같은 정답으로 함께 쓰는 것이다. 스케일러와 분류기는 두 버전 모두 학습 영상의 특징과 라벨에만 적합했다. 새 스케일러·헤드의 적합과 사전에 정한 규칙에 따른 각 모델의 임계값 선정은 이 변경에 따른 절차이며, 특정 증강 한 가지의 인과 효과를 측정한 것은 아니다.

- `protocol.json`, `protocol_receipt.json` — 시제품 절대 기준·상대 허용치·조건/가중치·임계값 규칙·분할/코드 식별자. 각 원본의 7개 조건/seed 판정 비중은 같다.
- `INPUT_REVIEW.md` — 실제 이미지와 마스크, 조건 변화 후 관측 범위.
- `hypothesis.json` — K0 전체 검증 조건의 수치, 실제 실패 사례, K1에서 바꾸고 유지할 요소, K0 진단/헤드와 사전 규약 해시.
- `models/K0.joblib`, `models/K1.joblib` — 허용된 로컬 이진 헤드와 선택 임계값. 실행기는 업로드한 pickle을 해석하지 않는다. 원본 인코더는 `../surface_v1/models/resnet18-f37072fd.pth` 한 개를 공유한다.
- `K0_study.json`, `K1_study.json` — 조건/seed별 건수, 분모, 불량·정상 각각의 재현율과 단순 비교 모델. 검증 466장(불량 49, 정상 417)을 **모두 정상**이라 하면 조건마다 FN 49, FP 0, 불량 재현율 0%; **모두 불량**이라 하면 FN 0, FP 417, 정상 오경보율 100%다.
- `K0_validation_diagnostics.csv`, `K1_validation_diagnostics.csv` — 모델별 실제 검증 점수. 학습 스크립트의 진단이며 제품의 공통 실행기는 이 표를 읽어서 예측하지 않는다.
- `selection.json` — 검증 결과에 따라 공식 시험 평가가 허용되는지와 실패 근거, 고정된 소스·데이터·프로토콜·모델 해시. 모델 점수의 방향은 불량일수록 큼. 검증 원본에서 정상 오경보 예산 10% 내 불량 재현율 최대 → 오경보 최소 → 임계값 최대의 순서로 고른다. 모든 조건/시험에서 그대로 사용하며, 두 모델 점수 크기나 같은 시험 오경보율을 가정하지 않는다.

등록한 임의 이미지도 추론할 수 있으나, 이 개발/성능 근거는 KSDD2 범위에 한정된다. 생산 현장의 재검사비·안전·생산 정지 감소를 측정하지 않았다.
